# AboutSelphy — aboutselphy.com

The main website for the streamer AboutSelphy: who I am, what I stream, the
schedule, and a media kit for companies and sponsors.

Next.js 16 · Tailwind CSS v4 · shadcn/ui · Motion · PostgreSQL + Prisma 7 ·
central staff auth via `auth.aboutselphy.com`.

See [CLAUDE.md](CLAUDE.md) for architecture, conventions and the roadmap.

```sh
pnpm install
cp .env.example .env
pnpm dev -p 3002
```
